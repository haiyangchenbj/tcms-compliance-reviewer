# TCMS Compliance Reviewer

**Part of the `tcms-*` family** — brand-side content skills for tech-product marketing teams.
*Not for neutral third-party industry research — that is `industry-deep-dive-pipeline`'s job.*

## What it does

Pre-publish compliance and quality review of brand-side drafts (blogs, case studies, product write-ups, press releases) — checks facts, customer redaction, product naming, competitor rules, internal-info leaks.

It reports issues and fixes only; never auto-edits the original draft. For monthly performance analysis use `tcms-performance-analyst`.

## Trigger phrases

预审, 审核, 审稿, 终审, review, 检查初稿, fact check, 合规检查, 发布前审核, 发稿前检查, pre-publication review

## Pipeline position

`tcms-planner` (brief) → `tcms-writer` (draft) → `tcms-compliance-reviewer` (review) → `tcms-adapter` (channels) → `tcms-performance-analyst` (monthly report)
